SUNPETAL is a side-view daylight stealth game: Wren, a young botanist, crosses one long botanical garden past four patrolling gardeners to lift the last Sunpetal flower and slip out through the gate. Read the cones, crouch in tall grass, use tree shade and thrown pebbles, and let suspicion cool before it fills.
## Run it
```sh
node serve.ts
```
then open http://localhost:8080
